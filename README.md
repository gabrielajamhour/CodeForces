## Repository Structure

```text
CodeForces/
├── Difficulty 0800/    # Problems rated around 800
├── Difficulty 0900/    # Problems rated around 900
├── Difficulty 1000/    # Problems rated around 1000
├── Rounds/             # Solutions organized by contest
├── Models/             # Algorithm and data-structure experiments
└── README.md
```

Each problem folder generally contains the solution together with the original statement or notes about the reasoning process. Some problems also include failed attempts, intermediate reasoning, or alternative solutions.
